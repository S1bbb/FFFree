# Свободные аудитории — физфак МГУ

Статический сайт, сборка не нужна.

## Деплой на Vercel
1. Залей папку в репозиторий на GitHub (или `npx vercel` прямо из этой папки).
2. В Vercel: New Project → импорт репозитория → Framework Preset: **Other**, Build Command пустой, Output Directory: `.`
3. Deploy.

## На iPhone
Открой сайт в Safari → «Поделиться» → «На экран „Домой“».
Работает как приложение, без адресной строки и без интернета.

## На Android
Открой сайт в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
Тоже работает как приложение и без интернета.

## Обновление расписания
Расписание лежит в `data/schedule.json`, его собирает `scraper.py` с ras.phys.msu.ru.
Сайт сам считает по нему занятые аудитории и показывает, какая группа где сидит.

Автоматически: GitHub Action «Обновить расписание» запускается по понедельникам,
и если расписание изменилось, коммитит его и поднимает `VERSION` в `sw.js`.
Запустить вручную: GitHub → Actions → «Обновить расписание» → Run workflow.

Вручную со своего компьютера:
```
pip install requests beautifulsoup4
python scraper.py
```
Затем поменяй `VERSION` в `sw.js` и запушь.

Ссылка на конкретную пару: `/#d3p2` — среда, 2 пара.
